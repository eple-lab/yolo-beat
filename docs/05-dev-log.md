## 2026-11-10 (1일차): 무엇을 만들까

### 1. 첫 질문
- **eple:** "YOLO 서비스 만들 거야. 노트북 웹캠에 적용해서. 자세하게 어떤 서비스를 만들 수 있을까?"
- **Claude:** 요청을 한 줄로 요약하고, YOLO가 하는 일 5가지(Detect, Pose, Segment, Track, Classify)를 표로 정리했다. 노트북 성능(nano 모델은 CPU에서 실시간 근처, 추정)도 말했다.
- 서비스 후보 6개, 만드는 방식 3가지(Python 데스크톱 / 서버+웹 / 브라우저만)를 제시했다. 추천은 "책상 앞 코치"(D-01).

### 2. 요가 자세 가이드 검토
- **eple:** "ultralytics 이걸로 하는 거지? 화면에 요가 동작 띄워 주고(난이도 1~10), 동작이 맞는지 어떻게 해야 맞는지 가이드해 주는 서비스는 어때?"
- **Claude:** 그 저장소가 맞다고 답했다. 판정 방법(관절 각도 + 허용 오차)과 제약 7가지를 정리했다. 2D 한계, 전신 촬영, 누운 자세, 관절 가림, 손가락 없음, 화면을 못 봄, 피드백 깜빡임이다. 난이도 데이터 작업, 저작권, 안전, **AGPL-3.0 라이선스**도 말했다.
- **eple:** "그럼 별룬데. 간단하게 할 수 있으면서도 기발한 거 없을까?" (D-02)

### 3. 간단하고 기발한 후보
- **Claude:** 학습 없이 하루 이틀 안에 되는 5개를 냈다. 어깨 너머 감시자, 실루엣 통과 게임, 보물찾기, 허공 드로잉, 몸 악기. 추천은 실루엣 통과 게임이었다.
- **eple:** 몸 악기 항목을 붙여 넣으며 "이거 좋아 보여" (D-03)

### 4. 몸 악기 계획
- **Claude:** 무엇을, 왜, 어떻게를 정리하고 정할 것 3개를 물었다.
  - ① 악기 구성: 드럼 패드 / 피아노 / 둘 다 → 추천 드럼
  - ② 소리 조건: 진입 순간 / 진입 + 속도 → 추천 진입 순간
  - ③ 소리 소스: numpy 합성 / 샘플 파일 → 추천 합성
- 단계 계획: 0 환경 확인 → 1 웹캠 + Pose + FPS → 2 구역 + 충돌 판정(테스트 먼저) → 3 소리 → 4 튜닝
- 다운로드 규모(PyTorch 포함 수백 MB, 모델 6MB)를 미리 알렸다.
- **eple:** "좋아. ①②③은 추천대로 하고, 환경 확인 먼저 해 줘" (D-04, D-05, D-06)
